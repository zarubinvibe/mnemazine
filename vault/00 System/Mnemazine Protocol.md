# Mnemazine Protocol

## Короткий ответ

The vault contains finished knowledge only.

Первичное распознавание, copied fragments, transcripts, screenshots, and unverified dumps stay in `inbox/`, `.mnemazine/cache/`, or `99 Archive/`.

## Источники

This file documents the repo fixture protocol.

Every durable note should contain:

- clear title;
- short explanation;
- source links;
- verified facts;
- open questions;
- practical use;
- related notes.
