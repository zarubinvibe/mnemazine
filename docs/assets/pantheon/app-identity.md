# Application identity

The application mark is a horizontal graph with eight nodes and nine bonds.
Use `app-icon-mnemazine.png` for the launcher: the graph sits in a wide glass tile above marble Olympus Mons.

The menu bar uses the same graph as a native monochrome template image in
`macos/Sources/Mnemazine/MnemazineMark.swift`. macOS chooses its color for the current appearance.
The drawing is 32 by 18 points; the status item reserves 40 points.

The scroll in older narrative illustrations describes source material. It is not the application logo.
Do not substitute a radial cluster or squeeze the mark into a square.
