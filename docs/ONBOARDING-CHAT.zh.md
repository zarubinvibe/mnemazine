你好，我是 Filipp Zarubin。我做 Mnemazine，是因为收藏的链接、截图、PDF 和语音不会自动变成知识。它们要被读懂、核验，并放到以后做项目时能找到的位置。

这个聊天指南用于第一次真实运行。我会在每一步之前说明我要做什么、磁盘上会改变什么，并在真的有选择时给你选择。

<!-- owner-greeting:end -->

## 第 1 步：检查这台电脑

**我在做什么：** 我检查 Node.js、Python、git、npm，并确认这是不是 macOS。

**为什么：** Mnemazine 优先使用本地工具。macOS 有 Apple Vision 可以本地识别截图；其他系统也能用，但图片可能需要模型或手动文本。

**磁盘上会改变什么：** 不会改变任何东西。这一步只读取状态。

**你会得到：** 一份清楚的清单：现在能用什么，还缺什么。

**岔路：** 如果没有 Node.js，先安装它。如果只是没有 Apple Vision，可以继续，先处理文本、PDF 和链接。

## 第 2 步：选择收件箱

**我在做什么：** 我选择你以后放原始材料的文件夹。

**为什么：** 一个固定入口能避免材料散落在很多地方。你不需要记住五个导入路径。

**磁盘上会改变什么：** 可能会创建收件箱文件夹，通常是 `~/Desktop/Mnemazine Inbox`。

**你会得到：** 一个可见的位置，用来放截图、PDF、链接、音频和短笔记。

## 第 3 步：选择知识库

**我在做什么：** 我把 Mnemazine 连接到你的 markdown 知识库。

**为什么：** 输出是普通文件。你可以用 Obsidian 读，用 grep 搜索，自己备份，也可以以后迁移。

**磁盘上会改变什么：** 本地配置会记录知识库路径；知识库里会出现系统笔记和索引。

**你会得到：** 一个活的知识库，而不是另一个封闭软件仓库。

**岔路：** 你可以使用现有 Obsidian vault，也可以让 Mnemazine 创建一个新文件夹。

## 第 4 步：决定是否使用 deep mode

**我在做什么：** 我询问是否允许模型辅助的研究和拆分。

**为什么：** 本地模式更便宜也更私密。deep mode 能研究、拆分和核验复杂材料，但文本可能会发送给你选择的模型服务。

**磁盘上会改变什么：** 只改变本地设置。已有笔记不会因为这个选择被重写。

**你会得到：** 在材料离开电脑之前，先知道隐私和成本边界。

## 第 5 步：运行一小批真实材料

**我在做什么：** 我处理你收件箱里的五到十个真实文件。

**为什么：** 演示文件几乎证明不了什么。你自己的文件才能证明 OCR、来源追踪、原子化和 gate 是否真的工作。

**磁盘上会改变什么：** 完成的笔记会出现在知识库里；原始文件只会在覆盖被证明后移动到持久归档。

**你会得到：** 可搜索的笔记，带来源、核验状态、项目关联和未来项目类别。

## 第 6 步：验证结果

**我在做什么：** 我运行 doctor 和质量 gate。

**为什么：** 只有机器证明没有文件被静默丢失、且新笔记符合 schema，运行才算结束。

**磁盘上会改变什么：** 检查主要是只读，可能写报告或状态收据，但不会编辑你的笔记。

**你会得到：** 可信的通过/失败结果；如果失败，会看到明确的修复项。

```bash
npm run doctor
```
