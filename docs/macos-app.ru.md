# Мнемозина в строке меню macOS

<img src="assets/pantheon/app-icon-mnemazine.png" alt="Иконка Мнемозины: вытянутый золотой граф в стеклянной плашке над мраморным Олимпом на Марсе" width="100%">

Приложение доступно как предварительная версия из исходников. Оно открывает поиск, добавление материалов и очередь из строки меню. Значок: вытянутый граф связанных узлов. На иконке запуска тот же граф расположен над Олимпом.

Поисковая капсула и четыре круглые стеклянные кнопки стоят рядом с прозрачными промежутками: «Ссылка», «Файлы», «Буфер», «Настройки». Выбранная кнопка перемещается к началу строки и исчезает из внешнего ряда. Повторное нажатие возвращает поиск. Выбранное действие раскрывается ниже только при необходимости.

Локальное приложение: очередь задач, добавление файлов, поиск, справки и переход к источникам. Нужны macOS 14+, Node.js и настроенный проект Mnemazine. Для сборки нужен Swift SDK с macOS 26 (Xcode 26 или новее); на macOS 14–15 приложение использует системные материалы.

```sh
npm run app:build
open .mnemazine/tmp/Mnemazine.app
```

Сборка создает локальный `.app` с ad-hoc подписью. Готового нотарифицированного приложения для скачивания и установщика нет. Внутри остаются пути к текущему проекту и Node.js: приложение не содержит самостоятельный backend. При переносе проекта или Node.js обнови пути в настройках.

Открывай созданный `.app` через Finder или командой выше. Если перенесешь его в папку «Программы», запускай оттуда. Запуск и повторное открытие сразу показывают панель; значок графа в строке меню также открывает ее. После Esc процесс остается запущен, «Выйти» завершает только интерфейс.

Нажми значок графа в строке меню. В режиме «Файлы» выбери документы (⌘O) или перенеси их в любую часть открытого окна. Появятся имена выбранных файлов. Нажми «Обработать» и подтверди передачу содержимого модели для разбора и веб-обогащения. Сам перенос ничего не отправляет. Исходные файлы сохраняются. Закрытый значок файлы не принимает.

В режиме «Поиск» введи запрос и нажми Enter. «Сделай справку: тема» создает справку, остальные запросы запускают поиск. Результат открывается отдельным окном.

Поиск по умолчанию локальный. AI включается в настройках и требует подтверждения перед каждым запросом. Приложение не сохраняет включенный глубокий режим между запусками.

Настройки раскрываются прямо в панели. Контекстное меню строки (правая кнопка мыши) открывает очередь или выход. Очередь показывает готовность, ошибки, отмену и повтор в отдельном окне. Фоновую обработку выполняет backend проекта, она не зависит от открытой панели.

В режиме «Ссылка» вставь http/https-адрес, название или короткий текст. Enter и кнопка «Исследовать и добавить» сначала запрашивают подтверждение. Название сохраняется как запрос, не как установленный факт; полный текст страницы и расшифровка видео не гарантируются. Лимит текста 8 КиБ.

«Буфер» читает текущий текст, ссылку или файлы только по нажатию этой кнопки либо «Прочитать снова». Показывается предпросмотр. Слежения за буфером и истории нет. Кнопка «Добавить в память» требует отдельного подтверждения; длинный текст предложено сохранить в файл.

В настройках выбери папку проекта и исполняемый файл Node.js, если приложение не нашло его само. Выбор сохраняется в локальных настройках macOS. Настройка моделей и хранилища остается в Mnemazine; отдельной базы у приложения нет.

Настройки показывают обнаруженные CLI. Встроены адаптеры Claude Code, Codex и Kimi; для другого CLI нужен проверенный адаптер. При ошибке квоты или частоты запросов backend пробует следующего разрешенного исполнителя с нужными возможностями и допуском к данным. Наличие CLI не подтверждает авторизацию или доступную квоту. Если замены нет, задача показывает ошибку. Подробности: [переключение CLI](cli-failover.ru.md).

Поисковая капсула и круглые кнопки используют нативное стекло без общей подложки. На macOS 26 их объединяет GlassEffectContainer. Стабильные glassEffectID и matchedGeometry переходы связывают перемещение выбранной кнопки.

При наведении файлов строка превращается в зону «Отпусти файл здесь»; после переноса показывает имя принятого файла. Наведение ничего не читает из буфера и ничего не отправляет.

Значок использует NSStatusItem, содержимое показывает прозрачная NSPanel. Панель остается открытой при переходе в Finder. Закрыть ее можно по Escape, повторным нажатием значка или переходом к результату либо очереди.

Выделение текста и подписи VoiceOver сохранены. Окна настроек, очереди и результата используют нативное стекло macOS 26 в режиме regular; на macOS 14–15 предусмотрено размытие. При «Уменьшении прозрачности» поверхности непрозрачные. При «Уменьшении движения» анимации отключены. Проверка поведения настоящими пользователями пока не проведена.

Проверка без обработки пользовательских файлов:

```sh
swift test --package-path macos
```

Ручная приемка: запуск из Finder, настройка путей, локальный поиск по тестовому vault, перенос тестового файла с явным подтверждением, закрытие и повторный запуск приложения, просмотр результата, отмена и повтор. Отдельно проверь клавиатуру, VoiceOver, светлую/темную тему и уменьшение прозрачности. Пользовательские файлы для smoke-проверки не нужны.

Проверка общих поверхностей: `WindowSurfaceTests` измеряет реальное покрытие зоны
закрытия, safe area содержимого и радиусы до/после resize, а также переключение
непрозрачной подложки. Это не заменяет визуальную проверку тем и VoiceOver.

`SpotlightModeTests` проверяет маршрутизацию режимов, предел текста и чтение буфера
только по явному выбору через подставленный источник. Реальный буфер тесты не читают. Видимая ошибка карточки очереди передается
как accessibility value. Визуальный прогон темной темы выполнен на macOS 26.5;
фактическое голосовое чтение пока не подтверждено, несмотря на проверенный AX-вывод.
