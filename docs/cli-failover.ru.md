# CLI и переключение при лимитах

Настройки приложения показывают найденные CLI и время паузы после лимита. Обнаружение читает PATH и стандартные каталоги установки; не выполняет вход в аккаунт, не вызывает модель и не проверяет баланс. «Найден» не означает, что авторизация и квота действуют.

Встроены адаптеры Claude Code, Codex и Kimi. Другой CLI подключается записью в `config/cli-registry.local.json`: `invoke`, `probe`, `model`, `effort`, `data_classes`, `capabilities`, `cost_tier`, `local`. Ядро поддерживает stdin/аргумент промпта и три механизма вывода. `json_schema_inline` совместим с протоколом Claude, `json_schema_file` с Codex; `json_in_prompt` подходит CLI с обычным текстовым ответом. Флаги конкретного CLI нужно проверить по его документации. Само наличие программы не даёт ей разрешение читать память. Неизвестные найденные инструменты отображаются как требующие адаптера.

При неуспешном вызове распознаются quota и rate limit. CLI получает общую для процессов паузу: по умолчанию 5 часов для квоты, 60 секунд для rate limit. Это защитный интервал, не подтверждённое время сброса подписки. Состояние в `~/.mnemazine/cli-cooldowns`, путь меняет `MNEMAZINE_CLI_COOLDOWNS`. После истечения паузы CLI снова пробуется. Успешный текст со словом «лимит» не считается ошибкой.

Следующий исполнитель должен иметь допуск к классу данных и все требуемые возможности. Веб-исследование не переключается на CLI без web_search. Запрет отправки персональных данных не снимается ради обхода лимита. Первичный провайдер проходит тот же контроль, что и резервные. Если подходящих CLI нет, вызов завершается явной ошибкой.

Общий бюджет цепочки по умолчанию 7 минут; `MNEMAZINE_LLM_CHAIN_TIMEOUT_MS` или `opts.totalTimeoutMs` меняет его в пределах 30 минут. `MNEMAZINE_LLM_FALLBACK=0` отключает резервную цепочку. `opts.provider_used` содержит фактического исполнителя, `opts.attempts` категории попыток без содержимого документов и stderr. Модель и effort в реестре не подтверждают фактическую модель процесса: запускаемые флаги задаёт invoke/адаптер, это отдельная граница конфигурации.

Проверки: `node scripts/mnemazine-cli-discover.mjs`, `node tests/test-cli-failover.mjs`. Тесты используют имитации CLI, без платных вызовов.

## Завершение обработки

Финальная проверка pipeline теперь предшествует архивированию копии источника. Ошибка проверки оставляет её во входящих задания. Общий baseline качества читается из канонического состояния репозитория и проверяется на принадлежность vault; изолированное состояние задания не заменяет baseline. Ранее неудачные задания автоматически не переигрываются.
