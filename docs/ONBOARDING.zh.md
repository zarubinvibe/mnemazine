# 上手引导

这份引导假设你从来没有跑过本地的知识系统。每一步都写清楚要做什么，以及之后应该看到什么。

最短的路是对话式的：在 Claude Code 里打开项目并运行 `/mnemazine-setup`。谟涅摩绪涅会自己完成安装，一次问一个问题，没有你的同意不装任何东西。下面是同一条路，靠双脚走。

你需要 Node.js 20 以上、Python 3.11 以上和 git。建议用 Mac：本地识别截图依赖 Apple Vision，只有那里有。在 Linux 上其余部分照常工作。

1. **把项目放进一个目录。**

   ```bash
   git clone https://github.com/zarubinvibe/mnemazine.git "$HOME/Desktop/Mnemazine"
   cd "$HOME/Desktop/Mnemazine"
   ```

   你会看到目录出现，终端提示符进入其中。

2. **在写入任何东西之前先看计划。**

   ```bash
   MNEMAZINE_SETUP_DRYRUN=1 bash setup.sh
   ```

   你会看到安装将会做什么。不装、不移动任何文件。

3. **运行带引导的安装。**

   ```bash
   bash setup.sh
   ```

   它会问你收件箱放在哪里、要不要 Telegram 机器人。本地引擎如实回答：缺少的那个会打印“能力降级”的行，而不是假装已安装。

4. **检查状态。**

   ```bash
   npm run doctor
   ```

   你会看到全绿，或者一行红色以及修好它的命令。退出码 0 表示全绿，2 表示能用但能力降级，1 表示有失败。

5. **把真实材料放进收件箱。** 截图、PDF、存下来的文章、语音。放你自己的五到十个文件，而不是玩具样例。

   你会看到它们躺在一个目录里等着。

6. **运行流水线，看着各个阶段走过去。** 守卫先做快照并给每个文件算哈希，本地引擎读取，事实拿到来源，长材料被切成独立的笔记，每条落进自己的分区。

   你会看到 `vault/` 里出现笔记：标题读得懂，来源可核对。

7. **用 Obsidian 打开知识库。** 让它指向 `vault/`。

   你会看到分区、笔记之间的连接，以及“这条笔记对你有什么用”的那一段。

8. **把同一个文件再放一次。** 拿一个已经处理过的文件，重新丢进收件箱。

   你会看到它按哈希被认出并跳过。重复文件花费零 token，省钱正是从这里来的。

9. **读每周简报。** 它写清楚有什么变化、什么值得花时间：知识自己回到你面前，而不是等你想起来。

10. **认真决定要不要开深度模式。** 关闭时这次运行不花钱，材料也不离开机器；打开时内容会发给你选定的模型服务。这个答案属于你，会被询问，不会被替你决定。

## 以后怎么更新

以后有了新版本，不用重新克隆：在 Claude Code 里打开项目并运行 `/mnemazine-update`。它先告诉你有什么变化，只做快进式更新，不动你的设置和数据，更新之后还会重新自检。

## 如果这份引导帮到了你

如果 Mnemazine 把那堆材料变成了你真正会用的东西，请点亮星标：[https://github.com/zarubinvibe/mnemazine](https://github.com/zarubinvibe/mnemazine)。这只要一秒，却决定别人能不能找到这个项目。

你已经从头到尾跑过一遍，所以你正是能改进它的人。路径很短：先 fork 仓库，建一个分支 branch，提交 commit，推送 push，然后开一个 Pull Request。请不要直接向 `main` 推送，发布闸门会拒绝。

发现某一步写错了？到 [https://github.com/zarubinvibe/mnemazine/issues](https://github.com/zarubinvibe/mnemazine/issues) 开一个 issue，写清楚你运行了什么、看到了什么。
